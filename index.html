💡 왜 필요한가요?
AI 컨설팅은 Claude AI를 사용해요. 학원장님 본인 계정의 API Key가 필요하고, 한 번만 발급받으시면 학생/학부모 상담 시 자유롭게 쓸 수 있어요.
STEP 1
Anthropic 계정 가입

👉 console.anthropic.com 접속 → Sign Up → Google 계정 가입 (빠름)

STEP 2
결제 정보 등록 + 충전

Plans & Billing → Add credit → 카드 등록 + 최소 $5 충전 (약 7,000원, 오래 사용)

STEP 3
API Key 생성

API Keys → Create Key → 이름 (예: Consulting) → 키 복사 (sk-ant-api03-...)

⚠️ 키는 한 번만 보입니다! 꼭 복사하세요.

STEP 4
이 시스템에 입력

위 입력란에 키 붙여넣기 → 저장 → "✓ 저장됨" 확인 → AI 분석 받기 가능!

💰 비용 안내
  • AI 분석 1회 = 약 50~150원
  • $5 충전 = 약 30~80회 사용 가능
  • 구독 X, 사용한 만큼만 차감
🔒 보안 안내
  • 키는 이 브라우저에만 저장 (다른 컴퓨터에서 쓰려면 재입력)
  • Anthropic API로 직접 전송 (제3자 서버 경유 X)
❓ 자주 묻는 질문
  • 한국 카드 됩니까? 해외결제 가능한 카드면 OK (VISA/Master)
  • "401 오류" 뜨면? 키 오류 또는 충전금 부족
  • 키 분실 → 콘솔에서 재발급
